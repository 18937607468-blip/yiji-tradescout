## 现场无网络或服务受限

- 使用已经保存的官网原文、URL、抓取时间与历史查询，明确说明保存日期和缓存来源。
- 无 Tavily Key：预览查询仍可用；提供人工核对的官网或 CSV。访问官网仍需网络，不把该路径说成离线抓取。
- 无 B1X Key：使用证据展示、规则筛选、跟进、记忆 diff 和材料计算；明确“本轮没有调用模型”。
- 完全断网：本地已启动且迁移完成的工作台可演示合成样例的保存与回读，或展示 `docs/screenshots/` 的真实截屏，并运行 `npm test`；截图不冒充实时交互。
- 同名企业、弱证据、401/429、解析错误均展示真实失败与待核验状态，不临时生成“成功名单”。
