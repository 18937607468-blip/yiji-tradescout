### 公开联系入口的验证边界

BPW 原站展示电话 `+49 (0) 2262 78-0`，但原 HTML 电话链接是 `tel:+490226278-0`。平台如实保存链接原文，没有猜改国际拨号格式；该入口没有实拨验证，不能称为已验证电话。官网归属、公开联系方式、采购职务、当前需求和付款能力是不同事实，分别保留验证状态。BPW 本次仅作官网归属与持久化验收，不代表已确认买家或成交。

## 仍需真实输入验收

1. 用户登录实际账号，在设置中用已有 B1X Key 运行连接验证与一次真实官网/询价提取，查看返回模型、请求 ID、tokens 和引用原文。
2. 用户自己的第二台设备打开正式 HTTPS 网址；登录同一账号检查相同记录。云浏览器可访问不等于已验收现场 Windows 网络。
3. 企业确认一小批实际客户的合格标准、规格与报价数据。当前没有商业精度、回复率、成交或收入提升实测。
4. 录制实际运行的演示备份，并明确标注录像，现场检查字体和投屏。
5. 搜索服务当前限流；需要核对提供方可用配额。B1X 模型 Key 的额度不提供搜索额度，手工取证路径也不等于已恢复自动搜索。
